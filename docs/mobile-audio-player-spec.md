# Aftertone — спецификация Android-приложения

## Цель

С нуля создать аккуратный офлайн-плеер для POCO X6 Pro. Приложение хранит импортированные пользователем аудиофайлы в приватной памяти телефона, воспроизводит их без сети и сохраняет локальные плейлисты и избранное.

## Объём продукта

- Пользователь выбирает аудиофайлы штатным Android-пикером; приложение копирует их в своё локальное хранилище и читает доступные теги и обложку.
- Библиотека: список и поиск по импортированным трекам, избранное и удаление локальной копии.
- Плейлисты: создание и удаление пользовательских списков, добавление и исключение локальных треков.
- Воспроизведение: очередь из библиотеки/плейлиста, play/pause, следующий/предыдущий трек, перемотка, случайный порядок, повтор, системное уведомление и управление с экрана блокировки.
- Дизайн Aftertone — самостоятельный тёмный музыкальный интерфейс с тёплым светлым текстом, лаймовым акцентом, выразительной типографикой, обложками и ненавязчивой анимацией переходов/визуализатора. Это вдохновение качеством музыкальных приложений, не копия брендинга или экранов Apple Music.
- Интерфейс рассчитан на узкий экран телефона, безопасные зоны, крупные сенсорные цели, состояния пустой библиотеки и ошибок импорта.

## Границы

- Не скачивать, не извлекать и не обходить DRM для контента Apple Music, Spotify или иных стриминговых сервисов. Ссылки на плейлисты не дают разрешения на распространение защищённых аудиофайлов.
- Не добавлять потоковый каталог, аккаунты, рекламу, трекинг или сетевые разрешения. Приложение играет локальные файлы, которые пользователь имеет право хранить.
- Если источник выбран в облачном файловом провайдере, он может потребовать сеть во время импорта; после успешного импорта копия лежит в памяти приложения и играет офлайн.
- Удаление трека внутри Aftertone удаляет импортированную копию. Удаление приложения удаляет его приватную медиатеку; это нужно объяснить в интерфейсе.

## Технические критерии

- Нативный Android: Kotlin, Jetpack Compose, Media3 ExoPlayer/MediaSessionService; без WebView.
- `minSdk 26`, `compileSdk 37`; приложение устанавливается на Android-телефон POCO X6 Pro.
- Доступ к исходному файлу — только через системный выбор файлов; постоянные широкие разрешения на общие файлы не запрашиваются.
- Сборка `debug` для CI; подписанная `release`-сборка публикуется автоматически в приватный GitHub Release после успешных тестов.
- Версия APK автоматически повышает `versionCode`, чтобы последующее обновление можно было установить поверх предыдущего.
