# Aftertone

Нативный Android-плеер для собственной музыки, сохранённой на телефоне. Интерфейс оптимизирован для небольшого экрана: быстрый доступ к медиатеке, избранному и подборкам, мини-плеер снизу, крупный экран воспроизведения и плавные переходы.

## Скачать APK

Последняя сборка доступна в [GitHub Releases](https://github.com/Neiro-irl/project/releases/latest/download/Aftertone.apk). Репозиторий приватный, поэтому для скачивания нужно войти в GitHub под аккаунтом, которому предоставлен доступ.

На POCO X6 Pro открой APK и подтверди установку из выбранного источника, если Android запросит разрешение. Приложение рассчитано на Android 8.0 и новее.

## Что умеет приложение

- Импортировать выбранные через системный файловый пикер аудиофайлы в закрытое хранилище Aftertone.
- Воспроизводить музыку офлайн и управлять ей из системного медиаплеера/уведомления.
- Искать треки, отмечать избранное, создавать подборки и удалять копию трека из Aftertone.
- Выбирать одну из пяти цветовых тем (фирменная Aftertone и четыре палитры); выбор сохраняется на устройстве.
- Импортировать MP3, M4A, AAC, FLAC, WAV, OGG/OGA, Opus, AMR и 3GP — если формат поддерживается декодером Android на устройстве.

Исходный файл при импорте не изменяется. При удалении приложение удаляет только собственную копию. Медиатека исключена из резервного копирования устройства и облака. Для локального воспроизведения не требуется аккаунт или подключение к сети.

Ссылки на плейлисты Apple Music и Spotify не являются аудиофайлами: приложение не скачивает защищённые потоковые треки и не обходит DRM. Импортируй аудио, которым ты владеешь или имеешь право пользоваться.

## Сборка на компьютере

Нужны JDK 21 и Android SDK Platform 37 / Build Tools 37.0.0. Проверки и локальный debug APK можно собрать так:

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

## Автоматическая сборка APK

GitHub Actions проверяет unit-тесты, lint и сборку при pull request и каждом push в `main`. После успешной проверки workflow собирает APK и публикует его в Releases; доступна также ручная команда запуска workflow. История версий — во вкладке **Releases**, самый свежий APK всегда доступен по ссылке выше.

**Подпись текущей автоматической сборки:** интеграция GitHub, доступная этой сессии, не имеет разрешения управлять Actions Secrets. Поэтому APK подписывается временным Android debug-ключом GitHub runner и устанавливается как обычное приложение. У такого ключа подпись может различаться между запусками; Android может не разрешить установить следующую версию поверх предыдущей — в этом случае удали старую версию и установи новую. Для бесшовных обновлений добавь в GitHub Actions Secrets значения `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`; workflow автоматически использует постоянный ключ, если все четыре секрета заданы.
